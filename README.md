## Project #1 — Predictive Smart Commute Card

**Domain:** Ride-Hailing / Mobility
**Status:** Concept → PRD → Interactive Prototype

### The Motivation
I noticed something while booking my daily Rapido ride — the app asks "Where to?" every single morning, even though I go to the same place at the same time, five days a week. That's unnecessary friction for millions of daily commuters. I wanted to explore what it would look like if ride-hailing apps actually leveraged the behavioral data they already have.

### What It Is
A predictive smart card concept for ride-hailing apps (Rapido, Ola, Uber) that eliminates the booking flow for predictable commutes. For users with 15+ rides/month, the app predicts the destination based on time-of-day, day-of-week, location clusters, and ride history — enabling true one-tap booking.

### What I Built
- Full Product Requirements Document (PRD) with AI prediction architecture
- Interactive mobile prototype with simulated booking flow
- Canvas-animated map with driver tracking
- Ride type selection modal with dynamic pricing
- Founder-level outreach strategy for Rapido

### Key Numbers
- **95%** target prediction accuracy for daily commuters
- **40%** reduction in time-to-booking
- **65%** minimum confidence threshold before showing the card

### Tech
React • Canvas API • Mobile-first UI • Simulated prediction logic

## Project #2 — SchemeWise

**Domain:** Fintech / Government
**Status:** Live
🔗 **[schemewise-one.vercel.app](https://schemewise-one.vercel.app/)**

### The Motivation
India has over ₹18 lakh crore sitting in government savings schemes — NPS, PPF, EPF, Sukanya Samriddhi, SCSS, and more. These are some of the best investment instruments in the world. But try understanding them? You'll land on government portals built in 2008, contradicting withdrawal rules across websites, and tax implications that change based on which regime you're on. Groww does mutual funds. Zerodha does stocks. ClearTax does ITR. Nobody does government schemes. I decided to fix that.

### What It Is
A free, AI-powered knowledge platform that answers any question about any Indian government investment scheme in plain, simple language. It doesn't invest your money — it makes sure you understand what you're investing in.

### Features
- **AI Chat Assistant** — Ask anything about NPS, PPF, EPF, SSY, SCSS, APY, NSC, KVP, POMIS, or Sovereign Gold Bonds. Powered by Claude Sonnet with suggested question chips.
- **Scheme Comparison Engine** — Side-by-side comparison of up to 4 schemes across interest rates, lock-in, tax status, and eligibility.
- **Personalized Recommendations** — Answer questions about age, employment, risk appetite → get ranked scheme suggestions.
- **Step-by-Step Withdrawal Guides** — EPF, PPF, NPS withdrawal walkthroughs with prerequisites, pro tips, and common rejection reasons.
- **Document Checklists** — Interactive checklists with progress tracking. Never make two trips to the bank.
- **Jargon Buster** — 50+ financial terms in plain English with Hindi translations.
- **Troubleshooting & Grievance Guides** — Resolution guides for UAN, PRAN, KYC mismatch, and claim rejections.
- **Interest Rate Dashboard** — Current rates for all small savings schemes.
- **Eligibility Checker** — Quick quiz to determine which schemes you qualify for.

### Key Numbers
- **10+** government schemes covered
- **50+** financial terms in the jargon buster
- **8** step-by-step withdrawal & troubleshooting guides
- **0** signup required — completely free and open

### Tech
React • Tailwind CSS • Claude Sonnet API • Vercel • Keyword-based fallback system

## Project #3 — LabDecode

**Domain:** HealthTech / AI
**Status:** Live
🔗 **[read-my-report.vercel.app](https://read-my-report.vercel.app/)**

### The Motivation
Every year, hundreds of millions of people worldwide get blood tests and lab reports. These reports are written for doctors — not patients. Reference ranges vary by age, sex, country, and lab. Most people glance at the "H" and "L" flags, panic or ignore them, and shove the report in a drawer. There's no product that bridges the gap between getting a lab report and actually understanding it. I built LabDecode to fill that gap — without overstepping into diagnosis.

### What It Is
A free, AI-powered web app that reads any medical lab report — blood tests, metabolic panels, organ function tests — and translates every parameter into plain, understandable language. Results are grouped by organ system with color-coded status indicators and evidence-based lifestyle suggestions.

**LabDecode does NOT diagnose. It does NOT prescribe. It does NOT replace a doctor.** It helps you understand your own health data so you can have better conversations with your doctor.

### Features
- **PDF & Camera Upload** — Upload PDFs or capture reports with your phone camera. Multi-page support for elderly users who can't save PDFs.
- **AI Report Analysis** — Claude Sonnet reads every parameter, categorizes by organ system, and explains each value in plain English.
- **10 Organ System Views** — Heart, Liver, Kidneys, Blood, Thyroid, Metabolism, Vitamins, Bones, Hormones, Inflammation.
- **4-Level Status System** — Excellent → Normal → Needs Attention → Review Recommended. No alarming language, no diagnosis.
- **Visual Range Bars** — Color-coded bars showing exactly where your value falls within the reference range.
- **Evidence-Based Lifestyle Suggestions** — Recommendations citing AHA, WHO, NIH, and peer-reviewed research. Never vague — always specific and actionable.
- **Unit Auto-Detection** — Works with reports from any country. Detects mg/dL or mmol/L automatically.
- **Age & Sex Adjusted Ranges** — Optional pre-analysis form adjusts reference ranges for age, biological sex, and pregnancy.
- **Report Comparison** — Upload multiple reports over time. Track trends with charts.

### Key Numbers
- **100+** lab parameters recognized and analyzed
- **10** organ system categorized views
- **2** unit systems supported (Conventional + SI)
- **7** strategically placed medical disclaimers
- **0** data stored on servers — completely private

### Safety by Design
- Every screen includes medical disclaimers
- Never uses alarming language ("Review Recommended" not "Critical")
- Never names diseases or predicts conditions
- Suggests which specialist to consult, not what to do
- All lifestyle suggestions cite published medical sources

### Tech
React • Tailwind CSS • Claude Sonnet API (Vision + Text) • PDF.js • Vercel Serverless Functions • localStorage
